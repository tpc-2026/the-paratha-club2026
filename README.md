# The Paratha Club — V4

V4 focuses on a real, app-like ordering journey while keeping payment deliberately unconnected.

Flow:
1. Food — choose box, flavours and quantity
2. Fulfilment — collection/delivery, date and time
3. Your details — contact and postcode
4. Review — confirm the whole order
5. Secure payment — placeholder hand-off for the future payment provider

The payment stage is intentionally not implemented yet. No card information is collected by this front-end.

Next: confirm the actual delivery radius/price, collection address, available days/times, final flavours, then implement a secure server-side checkout/payment integration.
